# Civ V - Vanilla baseline

This directory contains normalized rules and Simplified Chinese translations from the official Unciv 4.22.0 tag. `manifest.json` records the game build, source commit, upstream URLs, raw source hashes, and generated file hashes.

Refresh this snapshot from the repository root with:

```bash
python3 scripts/update_unciv_reference_data.py --ruleset "Civ V - Vanilla" --skip-schemas
```
