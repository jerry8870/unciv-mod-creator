# Survivor Camp MVP

[English](README.md)

这是一个可安装的 Unciv 扩展 Mod，把回合制生存循环映射到游戏已有的数据能力：

- **探索：** 侦路者探索随机地图。
- **采集：** 采集者改良野莓、木材和燧石。
- **建造：** 篝火、工作台和瞭望塔构成营地推进路线。
- **研究：** 营地工艺和庇护工程解锁下一阶段。
- **防守：** 营地守卫消耗燧石，并使用营地操练强化营地防线。
- **压力：** 生存压力困难度提前启动野蛮人，并提高其强度。

本 Mod 使用城市 Food、Growth、Happiness、资源、生产依赖、晋升和城市防御来表达**数据层生存压力**。它不宣称实现单位独立饥饿、实时昼夜、库存界面、强制单城市、保证自定义野蛮人生成或永久死亡。

## 安装和测试

1. 选择 `Civ V - Gods & Kings` 作为基础规则集。
2. 将此目录作为 Mod 安装，或使用仓库中的打包工具生成 ZIP。Mod 已明确声明依赖该基础规则集。
3. 运行 Ruleset Validator。
4. 使用 `Ember Kin` 文明和 `Survival Pressure` 困难度创建新游戏。
5. 按照 [DESIGN.md](DESIGN.md) 的流程测试。
6. 完成验证记录后，对照 [verification.json](../verification.json) 和 [VERIFICATION.md](../VERIFICATION.md)。

默认地图是随机的。困难度提供固定的初始单位，便于重复测试；在加入保存的小地图之前，资源和野蛮人的精确坐标仍然取决于地图生成结果。
