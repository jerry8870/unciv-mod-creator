# Deterministic test scenario

The MVP uses the `Survival Pressure` difficulty as its deterministic setup: it grants one Gatherer, one Trailfinder, and one Camp Guard at game start and starts barbarian pressure after one turn. The default map remains random for replayability.

For an exact placement regression, save a small map from the Unciv Map Editor and place the exported map file beside this README. The current acceptance record deliberately does not claim a fixed resource or barbarian coordinate until that map artifact is recorded.
